# G1 — 그룹 매핑표 (작업지시서#03 원안 + 2026-09-18 지시서#12 전수 감사 정정)

작성일: 2026-07-10 (원안) / **2026-09-18 정정** — 지시서#12 진행 중 9개 카테고리 전체를 구글시트 "그룹" 컬럼 실제값과 전수 대조한 결과, 원안 작성 이후 시트가 계속 편집되면서 여러 카테고리의 그룹 수·이름·품목 수가 원안과 달라진 것을 확인. **이 문서는 이제 "코드/시트가 어떻게 그룹핑하는지"를 반영하는 문서이며, 실제 소스는 항상 구글시트 "그룹" 컬럼이다** — 이 문서와 시트가 다시 어긋나면 시트가 맞다.

v1(`g1-group-mapping-proposal.md`)은 2026-07 시점 초안 이력으로만 참고.

## 철물/부자재 (118개) — **미해결, 지시서#12 범위 제외**

원안은 기능 단위 10개 그룹(본드/접착제·실리콘·피스못·타카·철물부속·오일스텐·사포·소모품·붓로라·공구마감소모품)으로 재작업 확정했으나, **시트에는 이 통합이 반영되지 않고 27개 세부 그룹**(예: "타카" 1그룹이 "타카핀 U자/DT·T/실타카/F/ST" 5개 그룹으로 쪼개진 채 방치)이 남아 있고, **12개 품목은 그룹 값 자체가 비어 있음**(엘리트 SS버튼 스텐, 폼용 건/크리너, 핫멜트건 대/소/알, 톱날, 톱자루, 프라이머, 오일스텐붓, 바르네 퍼티, 공캔 — 대부분 원안의 "공구/마감소모품"·"철물부속" 그룹에 해당). 이대로 그룹 페이지를 만들면 1~2품목짜리 페이지가 다수 생기므로, **시트 쪽 그룹 재정리(원안 10그룹 기준으로 통합, 미지정 12개 배치)가 먼저 필요** — 감독이 시트를 정리한 뒤 별도 지시서로 재개하기로 함(2026-09-18 확인).
