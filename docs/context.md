## 4. 확정된 UI/UX 방향

- **컬러**: 라이트 테마 기준. 브랜드 오렌지 `--color-accent-orange: #FF6B35`(로고 적용 시 지시서의 `#E8663C` 대신 기존 값 유지로 확정), 카카오 옐로 `#FEE500`.
- **레이아웃(대산 스타일 카드형, index.html 히어로 기준)**: 좌우 12~20px 여백, 요소 간 gap 8~10px, 카드 내부 padding 14~16px, 헤더는 둥근 카드 형태(24px radius)로 상단에 여백을 두고 떠 있는 형태(PC 기준).
- **검색창/카테고리 탭(calculator.html 모바일+태블릿 기준, `decisions.md` 확정)**: 풀블리드(좌우 0px, 100vw), 내부 텍스트는 좌측 44px(아이콘)/우측 16px padding 유지, 카테고리 탭 래퍼도 풀블리드 + 내부 좌우 16px padding으로 첫/마지막 탭 여백 확보. **헤더는 풀블리드 대상 아님**(기존 여백 유지).
- **카테고리 순서**: "전체"가 기본 활성 탭 → 마감자재 → MDF → 합판 → 인테리어합판 → 목재/구조재 → 석고보드 → 단열재 → 방부목/특수목/합성목 → 루바/집성판 → 철물/부자재 → (운반비, 그룹 UI 예외로 플랫 테이블 유지).

## 5. 협업 원칙 (`decisions.md` 재발 방지 원칙 7건 요약 — 전문은 `docs/decisions.md` 참조)

1. **커밋 전 git status 전체 파일 목록 체크** — 작업 범위의 파일이 전부 스테이징됐는지 확인 후 커밋.
2. **커밋·push는 감독 명시적 승인 후에만** — "확인 완료"/"승인" 문구 없이 임의 진행 금지.
3. **여러 파일 지시 시 파일별 개별 반영 확인** — 유사 컴포넌트를 공유하는 다른 파일도 교차검증.
4. **로컬 서버 no-store + cloudflared 터널 우선 사용** — 실기기 확인은 항상 cloudflared 링크로.
5. **정렬·여백 검증은 픽셀 좌표 수치 필수** — `getBoundingClientRect()` 실측치 첨부, "비슷함" 판정 금지.
6. **인라인 style 우선순위 확인** — 스타일 미적용 시 `!important`보다 먼저 HTML 인라인 `style=` 존재 여부 확인.
7. **모바일+태블릿 풀블리드가 기본 방침** — 별도 명시 없는 한 두 브레이크포인트 모두 대상, PC(1025px+)는 별도 미디어쿼리로 격리.
