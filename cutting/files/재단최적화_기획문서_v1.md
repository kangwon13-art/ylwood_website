# 영림 재단 최적화(가칭) — 기획 문서 v1

> 고객이 직접 재단 리스트를 입력하면 원장(판재) 위에 최적 배치를 자동 계산해 **로스율·필요 원장 수·견적가**를 즉시 보여주고, 그대로 주문·견적 요청까지 연결하는 웹 도구.
> 대상은 **합판·MDF 등 판재(2D)에 한정**한다. 몰딩·문틀 같은 선형재(1D)는 대상에서 제외하며, 최적화 엔진은 순수 2D 단일 구조로 둔다.

문서 구성: **1부 PRD** / **2부 기능정의서** / **3부 IA(정보구조)**

---

# 1부. PRD (제품 요구사항 정의서)

## 1.1 배경 / 문제
- 고객이 재단 사이즈를 문의 → 사장이 수기로 배치·로스 계산 → 견적 회신하는 과정이 반복적이고 시간이 든다.
- 로스(자투리) 계산이 사람마다·건마다 편차가 있어 견적 신뢰도와 마진 관리가 들쭉날쭉하다.
- 고객은 "이 사이즈로 자르면 원장 몇 장, 얼마인지"를 즉시 알고 싶어 한다.

## 1.2 목표
| 구분 | 목표 |
|---|---|
| 정성 | 고객이 스스로 재단 견적을 뽑을 수 있어, 사장의 반복 견적 업무를 대폭 줄인다 |
| 정성 | 로스 계산을 자동화·표준화해 견적 편차와 실수를 없앤다 |
| 정량 | 재단 리스트 입력 → 견적 확인까지 3분 이내 |
| 정량 | 자동 배치 로스율이 숙련자 수기 배치 대비 동등 이상 |


## 1.3 타깃 사용자
- **핵심: 고객** — 셀프 인테리어/시공자/소규모 목공소. 원하는 사이즈·수량을 알고 있고, 빠른 재단비 확인을 원한다.
- (운영 = 사장님은 코드에 단가를 고정해 두는 형태로 관리. 별도 관리자 페이지 없음)

### 페르소나
- **셀프 시공 고객**: 도면 없이 "가로 600 × 세로 400짜리 8장, 300×300 4장" 식으로 사이즈 목록만 안다. 로그인·복잡한 설정을 싫어한다.
- **반복 발주 시공자**: 비슷한 재단을 자주 넣는다. 저장·재사용, 빠른 재견적을 중시한다.

## 1.4 핵심 가치 제안
1. **즉시성** — 입력 즉시 배치도·장수·가격이 나온다.
2. **투명성** — 로스율과 계산 근거(원장 몇 장, 재단비)를 눈으로 확인.
3. **정확성** — 톱날 두께·결방향까지 반영한 실제 재단 가능한 결과.

## 1.5 범위 (Scope)

**In (MVP 포함)**
- 자재/원장 규격 선택 + 재단 항목(폭·길이·수량) 입력
- 2D 길로틴 재단 최적 배치 엔진 (로스 최소화) — 판재 전용
- **전단(트리밍) 옵션**: 원장 직각 보정용 가장자리 재단(기본 14mm 소실), 사용자 선택
- 결과: 원장별 배치도, 필요 원장 수, 로스율, 총 재단 컷 수
- 견적가 자동 산출 (**재단비만 — 온장 단가는 프로그램에 넣지 않음**)
- 견적 저장 / 주문·견적 요청 제출
- 운영자(사장) 관리: 자재·규격·단가·재단비 등록, 접수된 주문 확인

**Out (당장은 제외 / 후순위)**
- 결제(PG) 연동 — 초기엔 "견적/주문 접수"까지만, 대금은 오프라인
- 도면(DXF/DWG) 업로드 자동 인식
- 잔재(재고 자투리) 재활용 배치 — 2단계
- 회원 등급/포인트, 배송 추적
- 재고 자동 차감(재고 연동) — 이번 목적 아님, 후속 확장 여지로만 표기
- **선형재(몰딩·문틀 등 1D) 재단** — 대상 제외. 이 제품은 판재(합판·MDF) 전용

## 1.6 핵심 사용자 시나리오
1. 고객이 접속 → 자재(예: 18T 합판) 선택
2. 원장 규격 선택 or 기본값(예: 1220×2440) 사용
3. 재단 항목 입력: 폭·길이·수량, (옵션)결 지킴 체크
4. (옵션) 전단(트리밍) 적용 여부 선택
5. "계산" → 배치도 + 필요 원장 수 + 로스율 + 견적가 표시
6. 항목을 수정하면 실시간 재계산
7. 만족 → "주문/견적 요청" 제출(연락처·요청사항 입력)

## 1.7 성공 지표 (KPI)
- 견적 완료(계산까지 도달)율
- 견적 → 주문·견적 요청 제출 전환율
- 건당 견적 소요 시간
- 자동 배치 평균 로스율
- 사장의 수기 견적 처리 건수 감소량

## 1.8 제약 / 전제
- 재단기는 **직선 관통 재단(길로틴)** 기준 — 자유형 네스팅이 아니라 가로/세로 한 방향으로 끝까지 자르는 컷만 가능. 배치 알고리즘도 이 제약을 따른다.
- 톱날 두께(커프) **4.5mm**만큼 컷마다 손실 발생 → 계산에 반영.
- **결방향 제약·트레이드오프**: 자작합판·집성판 등은 결을 지켜 재단해야 하중을 견디고 **휨(뒤틀림)이 준다**. 결을 지키면(회전 제한) 수율이 낮아지거나 잔재 형태가 달라질 수 있다. 이 판단은 **사용자가 입력 단계 체크박스로 직접 선택**하며, 필요 시 반대 방식 결과를 비교로 확인할 수 있다(P1). (여기서 '휨'은 뒤틀림 현상)
- **과금 원칙 — 온장 기준**: 고객은 원장 **온장 단가 × 필요 장수**를 지불하고, 그 위에 재단을 받는 개념. 따라서 **로스(자투리) 비용은 전적으로 고객 부담**이며 별도 로스 청구가 없다. (로스율은 참고용 정보로만 표시)
- **전단(트리밍)**: 시작 기준 코너(좌상단)의 **상·좌 2면**을 잘라 직각 확보. **상전단 = 폭을 14mm 줄임**(길이엔 영향 없음), **좌전단 = 길이를 14mm 줄임**. **전길이 조각은 좌전단을 생략**(원장 끝을 기준면으로 사용)하므로 길이(예 2440)가 그대로 나온다. 전단 14mm에는 톱날 두께가 포함된다. 적용 여부는 사용자가 선택.
- 재단비 단가는 코드에 고정(관리자 페이지 없음). 변경 시 코드 수정.

## 1.9 단계(마일스톤)
- **1단계(MVP)**: 규격·두께 선택 + 재단 입력 + 2D 최적화 + 전단 옵션 + 배치도 + 재단비 산출 + 재단 계획서(미리보기·PDF)
- **2단계**: 견적 저장·재사용, 결 방식 비교 뷰, 잔재 활용 배치, 온장 단가·관리자 설정
- **3단계**: 결제 연동, 도면 업로드, 재고 연동

# 2부. 기능정의서

## 2.1 기능 목록
| ID | 기능 | 사용자 | 우선순위 |
|---|---|---|---|
| F-01 | 규격·두께 선택 | 고객 | P0 |
| F-02 | 재단 항목 입력/편집 | 고객 | P0 |
| F-03 | 2D 재단 최적화 엔진 (판재 전용) | 시스템 | P0 |
| F-04 | 배치도·결과 표시 | 고객 | P0 |
| F-05 | 재단비 산출 | 시스템 | P0 |
| F-06 | 재단 계획서 출력 (미리보기·PDF) | 고객 | P0 |
| F-07 | 견적 저장·불러오기 | 고객 | P1 |

## 2.2 상세 정의

### F-01 자재·원장 규격 선택
- **입력**: 자재 종류(합판 18T, 월패널 등), 원장 규격(**폭 × 길이**, 두께), **전단(트리밍) 적용 여부(체크)**
- **치수 규약**: 모든 치수는 **폭(짧은 변) × 길이(긴 변)** 로 표기하며, **길이 방향 = 원장 결 축**. (예: 4×8 → 1220 × 2440, 3×6 → 910 × 1820)
- **처리**: 규격(4×8/3×6)·두께를 선택. 규격은 코드에 등록된 값. 전단 적용 시 유효 원장 축소(상=폭−14, 좌=길이−14)
- **출력**: 선택된 규격·두께·유효 원장이 재단 화면에 반영
- **규칙**: 결방향은 길이 방향. 자작합판·집성판 등은 "결 재단 권장" 안내만 표시(강제 아님)

### F-02 재단 항목 입력/편집
- **입력**: 항목별 폭(mm), 길이(mm), 수량, **결방향 체크박스(결 지킴 on/off)**
  - 체크 규칙: **체크 시 입력한 '길이'가 결 방향**(원장 결 축)과 정렬 → 90° 회전 배제. (폭을 결로 쓰려면 폭·길이를 바꿔 입력)
  - 미체크 = 회전 허용(수율 우선). 기본값은 미체크이며 **사용자가 필요 시 직접 체크**
  - **방향 확정 기능 겸용**: 양쪽 치수 모두 원장 폭·길이가 아닌 조각(예 1200×300)은 방향이 두 가지 → 체크하면 입력 그대로 고정, 미체크면 엔진이 최적 방향으로 회전. 현장에서 고객에게 방향 확인하는 것을 체크로 대체
  - 편의: 상단에 '전체 결 지킴' 토글로 일괄 on/off, 행별 개별 조정 가능
  - 참고: **길이 == 원장 길이**로 입력하면 전길이 리핑(1D 재단)으로 처리되어 회전이 없다(F-03)
- **처리**: 행 추가/삭제/복제, 엑셀식 빠른 입력. 원장보다 큰 치수는 입력 단계에서 경고
- **출력**: 재단 리스트 테이블
- **검증**: 치수 > 0, 수량 ≥ 1, (폭 or 길이) ≤ 유효 원장(전단·커프 고려), 숫자만 허용

### F-03 2D 재단 최적화 엔진 (핵심)
- **입력**: 원장 규격, 재단 항목 목록, 파라미터(톱날 두께, 회전 허용 여부, 트림/여백, **전단 여유(적용 시 유효 원장 = 원장 − 전단 여유)**)
- **처리**:
  - 길로틴 제약 하의 2D 빈패킹 최적화 (재귀 이분할 / 휴리스틱 계열)
  - 목적함수: ①필요 원장 수 최소화 → ②로스율 최소화 (동률 시 컷 수·재단 편의 고려)
  - 컷마다 톱날 두께만큼 간격 확보
  - **결방향 처리**: 항목의 결 지킴 체크가 켜진 경우 입력한 길이를 원장 결 축(=길이 방향)과 정렬 → 90° 회전 배제. 미체크 항목만 회전 허용
  - **회전 처리**: ①조각 **폭=원장 폭**(예 1220) → 회전 불필요, 무조건 좌 시작 리핑. ②조각 **길이=원장 길이**(예 2440) → 회전 불필요, 전길이 크로스컷. ③그 외 → 결 지킴 체크 시 입력 그대로(회전 금지), 미체크 시 엔진이 0°/90° 중 최적 선택. 원장에 회전 또는 양방향 컷이 있으면 F-05/4.6의 2D 단가.
- **결방향은 사용자 선택**: 결 준수 여부는 F-02의 체크박스로 사용자가 정하며, 엔진은 그 설정대로 **한 번** 계산(단일 실행). 자동 두 모드 강제 없음
- **(선택·P1) 반대 방식 참고**: 요청 시 반대 설정(결 무시↔준수)으로도 계산해 원장 수·로스·잔재를 비교 제공
  - 예) 1220×2440에서 500×1200 4개 → 결 미체크 시 잔재 ≈400×1200(큰 덩어리), 결 체크 시 잔재 ≈220×2440(긴 띠). 트레이드오프 참고용
- **출력**: 원장별 배치 좌표, 필요 원장 수, 로스율(%), 총 재단 컷 수, 항목→원장 매핑
- **성능 목표**: 일반 규모(수십 항목) 수 초 이내
- **예외**: 어떤 항목도 원장에 안 들어가면 해당 항목 명시 후 나머지만 배치
- **단일 엔진 원칙**: 폭이 원장 폭과 같아 사실상 "길이만 자르는" 항목(1D 형태)도 2D의 특수 경우일 뿐이므로, 별도 1D 로직 없이 **동일 엔진이 그대로 처리**한다. (엔진은 순수 2D 하나로 유지)

### F-04 배치도·결과 표시
- **출력**: 원장별 배치도(각 조각 위치·치수·번호), 요약 카드(원장 수·로스율·컷 수·견적가)
- **(선택·P1) 결 방식 비교**: 요청 시 반대 설정 결과를 좌우로 대조(원장 수·로스율·잔재·가격). 기본 화면은 사용자가 체크한 방식의 결과만 표시
- **상호작용**: 조각 클릭 시 해당 항목 하이라이트, 원장이 여러 장이면 페이지/탭
- **부가**: 배치도 이미지 저장/인쇄(작업지시용)

### F-05 견적가 산출
- **입력**: 필요 원장 수, 컷당 재단비 단가표(2×2, 코드 고정), 원장별 컷 수·유형, 두께 tier
- **처리**: 재단비만 산출 (온장 단가는 프로그램에 넣지 않음)
  - **재단비 = 컷당 과금**. 단가는 **재단 방식(1D/2D) × 두께(12mm 기준)** 2×2:

    | 두께 | 1D (회전 없음) | 2D (회전 포함) |
    |---|---|---|
    | 12mm 이하 | 500원 | 700원 |
    | 12mm 초과 | 700원 | 1,000원 |

    - **적용 규칙(원장 단위)**: 한 원장이 **한 방향 컷만으로 완성**(조각 전부 전길이 → 리핑만, 또는 전부 전폭 → 크로스컷만)되면 그 원장 전 컷에 1D 단가. 그 외는 그 원장의 **전단 포함 전 컷**에 2D 단가. 세부 판정·컷 산정은 4.6.
    - 즉 1D/2D를 컷마다 섞지 않고 **원장별로 한 단가**를 적용한다.
    - 두께 tier는 선택한 두께로 자동 결정(≤12mm / >12mm)
    - 재단비 = Σ(원장별: 해당 원장 컷 수 × 그 원장 단가)
  - **단가표는 코드에 고정** — 변경 시 코드 수정. 관리자 페이지 없음.
- **출력**: 총 재단비 + 내역(1D/2D 컷 수별 금액). 원장 수·로스율은 참고 정보.

### F-06 재단 계획서 출력
- **기능**: 계산 결과를 **재단 계획서** 형태로 미리보기 + PDF 다운로드
- **계획서 구성**:
  1. **날짜** — 년·월·일·시간(생성 시점)
  2. **판재 정보** — 폭 × 길이, 두께(예: 1220×2440, 18T)
  3. **재단 결과**
     - 총 판재 수(필요 원장 수)
     - 재단 횟수(총 컷 수, 1D/2D 구분)
     - 총 재단비
  4. **재단 항목** — 입력한 사이즈(폭×길이) 및 수량 리스트
  5. **배치도** — 원장별 조각 배치 도면(엔진 실계산 좌표 기반 렌더링)
- **동작**: 결과 화면에서 [미리보기] → 계획서 팝업/오버레이 → [PDF 다운로드]
- **용도**: 고객이 재단 의뢰 시 사장에게 전달하거나, 사장이 재단실에 작업지시서로 사용

### F-07 견적 저장·불러오기 (P1)
- 로그인 or 접수번호/링크 기반으로 재단 리스트·결과를 저장·재호출

## 2.3 공통 검증·예외 규칙
- 치수/수량: 양수·정수 검증, 원장 초과 치수 경고
- 필수 설정 누락(단가 미등록 등) 시 견적가 대신 "가격 문의" 표기
- 계산 실패·미배치 항목은 사용자에게 명확히 안내(숨기지 않음)

# 4부. 엔진 상세 규칙 (길로틴 배치)

> 코딩 에이전시 구현 기준. 이 규칙대로 만들면 결과가 재현 가능하고 재단비/결방향/전단이 일관되게 반영된다.

## 4.1 용어·좌표
- 모든 치수는 **폭(W) × 길이(L)**, 길이 = 긴 변 = 원장 결 축. 단위 mm.
- 원장 좌표계: 좌하단 원점 (0,0), x축 = 폭 방향, y축 = 길이 방향.
- 조각 배치 = (x, y, w, l, 회전여부).
- kerf `t` = 톱날 두께 = **4.5mm**.

## 4.2 전처리 (배치 전 확정값)
1. **유효 원장** 계산(전단 적용 시): **유효폭 = 원장폭 − 14**(상전단, 폭 방향, 항상). **길이**는 기본 유효길이 = 원장길이 − 14(좌전단)이되, **전길이 조각(길이==원장 길이)은 좌전단을 생략**해 원장길이 그대로 사용 가능(원장 끝을 기준면으로). 전단 14mm에는 톱날 두께 포함. 미적용 시 0.
2. **조각 정규화**: 각 항목을 수량만큼 개별 조각으로 전개.
3. **회전 필요 판정**: `조각 길이 == 원장 길이`면 전길이 리핑만으로 완성(회전 불필요), 아니면 회전(크로스컷) 발생. 재단비의 원장별 1D/2D 판정은 4.6에서 원장 단위로 확정.
4. **회전 가능 여부**:
   - 결지킴 체크 O → 회전 불가(입력 길이가 결 축과 정렬 고정).
   - 1D 판정 조각 → 회전 불가(전길이 리핑).
   - 그 외(결무관·2D) → 0°/90° 둘 다 후보.
5. **불가 조각 선별**: 회전 포함 어느 방향으로도 유효 원장에 안 들어가는 조각 → `미배치`로 분리하고 사용자 경고. 나머지로 배치 진행.

## 4.3 길로틴 제약
- 모든 컷은 현재 직사각형을 **한 방향으로 끝까지 관통**(edge-to-edge)해 두 개의 하위 직사각형으로 분할한다. L자·자유 네스팅 불가.
- 배치는 이 분할의 재귀로 표현된다(각 노드 = 직사각형, 리프 = 조각 or 잔재).
- 인접 조각 사이, 조각과 분할선 사이에는 항상 **kerf `t`** 를 확보한다.

## 4.4 목적함수 (우선순위 고정)
온장 과금이라 "적은 원장 = 싼 견적 = 경쟁력"이 최우선.
1. **필요 원장 수 최소화** (1순위, 압도적)
2. 동수일 때 **로스 면적 최소화** (2순위)
3. 그다음 **총 컷 수 최소화**(재단비·시간 절감) + 같은 방향 컷을 모아 재단 편의↑ (3순위)
4. 최종 tie-break: 남는 잔재를 **잘게 흩지 말고 큰 한 덩어리로** 남기기(2단계 재활용 대비)

## 4.5 배치 알고리즘 (MVP = 결정적 휴리스틱)
메타휴리스틱(유전/어닐링)은 2단계로 미루고, MVP는 재현 가능한 결정적 방식으로 간다.

**스트립(shelf) 기반 재귀 길로틴 + 회전 후보 평가**
1. 조각을 **길이 내림차순**(동률 시 폭 내림차순) 정렬.
2. 현재 원장에 대해 **스트립**을 연다: 첫 조각의 길이(또는 회전 시 폭)를 스트립 높이로 잡는다.
3. 스트립을 폭 방향으로 채운다: 남는 스트립 폭에 들어가는 조각을 순서대로 배치(각 조각+kerf). 회전 가능 조각은 0°/90° 중 **남는 공간을 더 잘 채우는 쪽**을 선택.
4. 스트립이 더는 못 받으면 다음 스트립을 길이 방향으로 쌓는다(이전 스트립 높이+kerf 위에서 시작).
5. 원장 길이를 초과하면 그 원장을 마감하고 **새 원장**을 연다(2번부터 반복).
6. 모든 조각 소진 시 종료.
7. **다전략 탐색(필수)**: 위 배치를 **여러 시드로 반복**해 가장 적은 원장을 고른다 — ①조각 정렬순(길이순/폭순/면적순) ②전역 방향(비회전 배치 vs 결무관 조각을 90° 눕힌 배치). 각 조합으로 돌려 (원장 수 → 로스 순)으로 best 채택. 이 다방향 탐색이 없으면 전길이로 눕혀야 1장에 나오는 케이스를 놓친다(예: 500×1200 4개+400×1200 1개 → 눕히면 1장).

> 구현 노트: 스트립 방식은 길로틴 제약과 자연히 일치(스트립 경계 = 1차 관통 컷, 스트립 내부 = 2차 컷). 이 구조가 4.6 컷 태깅을 단순하게 만든다.

## 4.6 재단비 판정 → 단가 (확정: 원장 단위 1D/2D)
재단비는 컷당이되, **1D/2D 단가는 컷마다 섞지 않고 원장 단위로 하나만** 적용한다.
- **1D/2D 판정(원장 단위, 최종 확정)**: 한 원장이 **한 방향 컷만으로 완성**되면 1D. 세 경우:
  - ① 조각 전부 **전폭**(폭=원장 폭, 예 1220) → 리핑만 → **1D**. 전단 유무 무관, 무조건 좌 시작.
  - ② 조각 전부 **전길이**(길이=원장 길이, 예 2440) → 크로스컷만 → **1D**.
  - ③ 위 둘 중 하나라도 해당하면 1D.
  - 그 외(조각을 눕힘·양방향 컷/자투리 트림이 섞임) → **2D**.
- **방향 확정과 결 지킴 체크의 관계**: 양쪽 치수 모두 원장 폭·길이가 아닌 조각(예 1200×300)은 방향이 두 가지. **결 지킴 체크 = 입력 그대로 고정(회전 금지)** → 사용자가 방향을 확정하는 수단. **미체크 = 엔진 최적 회전 허용**.
- **단가 적용**:
  - 원장이 **1D**면 그 원장의 모든 컷에 1D 단가(≤12mm 500 / >12mm 700).
  - 원장이 **2D**면 그 원장의 **전 컷(전단 포함)**에 2D 단가(≤12mm 700 / >12mm 1,000).
- **컷 수 산정(원장별, 실제 톱질만)**:
  - 전단: **상전단 +1**(전단 적용 시 항상). **좌전단 +1**(전단 적용 & 전길이 조각만이 아닌 경우; 전길이만이면 생략).
  - 리핑(폭 방향 조각 경계): Σ(스트립 내 조각 수 − 1). 스트립 우측 잔재가 유의미(≈20mm↑)하면 +1.
  - 크로스컷(길이 방향 스트립 경계): (스트립 수 − 1). 상단 잔재가 유의미하면 +1.
- 재단비 = Σ over 원장 ( 그 원장 컷 수 × 그 원장 단가(1D or 2D) ).

> 참고: 조각이 전부 전길이(또는 전부 전폭)면 한 방향 컷만으로 끝나 1D 단가. 짧은 조각이 섞이거나 눕혀 배치돼 양방향/회전 컷이 생기면 그 원장 전체가 2D 단가가 된다.

## 4.7 kerf·경계 처리
- 조각 배치 시 우측·상단에 kerf `t` 예약. 원장 우측/상단 경계에 딱 붙는 마지막 조각은 바깥 kerf 불필요.
- 검증: `Σ(조각 치수 + 필요한 kerf)` 가 유효 원장 안에 들어가는지 항상 확인.

## 4.8 출력
- 원장별: 조각 리스트 `(번호, x, y, w, l, 회전여부, 항목ID)`, 잔재 직사각형 목록.
- 집계: 원장 수, 로스율(=미사용 면적/총 유효면적), 총 컷 수, **1D단가 적용 원장·컷 수 / 2D단가 적용 원장·컷 수**.
- (선택) 컷 순서: 1차 컷 → 2차 컷 순으로 나열(작업지시·검산용).

## 4.9 성능·예외
- 목표: 수십~수백 조각 수 초 내(결정적 휴리스틱으로 충분).
- **에러 방지(빈 화면 금지)**: ①조각이 유효 원장보다 큼(회전 포함) → 제외하고 "최대 ○○까지 가능" 안내. ②결 지킴으로 회전 불가해 안 들어감 → 사유 표시. ③전길이 조각+전단은 좌전단 생략으로 그대로 배치(길이 초과로 드롭 금지). ④입력 0/과다도 각각 메시지. 어떤 경우도 결과를 비워두지 않는다.
- 미배치 조각은 결과에 명시(숨기지 않음).
- 입력 검증(치수>0, 수량≥1, 유효원장 초과)은 엔진 진입 전 단계에서 완료 전제.

## 4.10 MVP에서 뺀 것(2단계)
- 잔재(스크랩) 재활용 배치, 메타휴리스틱 최적화, 결 준수↔무시 비교 자동 계산.
