영림 재단 견적 프로그램 — 직원용 사용법
================================

1. 실행
   같이 받은 "jaedan_app.html" 파일을 더블클릭하면 기본 웹브라우저(엣지/크롬)에서
   프로그램이 바로 열립니다. 설치·로그인·인터넷 연결 전부 필요 없습니다.
   (이 파일 하나에 계산 엔진까지 다 들어있어서, 이 파일만 있으면 됩니다.)

2. 사용 순서
   ① 왼쪽에서 원장 규격(4×8 / 3×6), 두께, 전단(트리밍) 적용 여부를 선택
   ② "재단 항목 입력"에 폭·길이·수량을 넣고 [추가] — 여러 개 계속 추가 가능
   ③ 값을 입력하는 즉시 가운데 배치도와 오른쪽 결과(원장 수·컷수·재단비)가
      자동으로 계산됩니다. 별도 계산 버튼 없음.
   ④ 원장이 여러 장이면 가운데 위쪽 탭("원장 1", "원장 2"...)으로 확인
   ⑤ 오른쪽 "재단 계획서 미리보기"를 누르면 고객/작업지시용 문서가 뜨고,
      거기서 "PDF 다운로드"를 누르면 브라우저 인쇄 화면이 뜹니다.
      → 인쇄 대상에서 "PDF로 저장"을 선택하면 PDF 파일로 저장됩니다.

3. 안 들어가는 항목이 있을 때
   입력한 조각이 원장 크기보다 크거나 배치가 안 되면, 오른쪽에
   "⚠ 원장에 안 들어가는 항목 N개"로 빨간 경고가 뜹니다. 조용히 사라지지
   않으니 이 경고가 보이면 사이즈를 다시 확인하세요.

4. 다른 사람에게 전달하고 싶을 때
   "jaedan_app.html" 파일 하나만 카톡·메일로 그대로 보내면 됩니다.
   받는 사람도 똑같이 더블클릭하면 바로 쓸 수 있습니다.

5. 단가·톱날 두께·전단 값 변경
   이 프로그램은 관리자 화면이 따로 없고, 재단비 단가표·kerf(4.5mm)·
   전단(14mm) 값이 파일 안에 고정되어 있습니다. 값을 바꾸려면 개발자에게
   요청하세요.
